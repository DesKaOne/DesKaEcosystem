# DesKaWeb

- DesKaWeb adalah website utama dari DesKaEcosystem. Website ini berfungsi sebagai pusat informasi dan portal utama untuk semua proyek yang berada di bawah ekosistem DesKaEcosystem.


## Backend
- Backend DesKaWeb dibangun menggunakan bahasa pemrograman golang. Backend ini bertanggung jawab untuk menangani logika bisnis, pengelolaan data, dan komunikasi dengan database. Backend juga menyediakan API yang dapat digunakan oleh frontend untuk mengambil dan mengirim data.

## Frontend
- Frontend DesKaWeb dibangun menggunakan bahasa pemrograman dart dengan framework flutter. Frontend ini bertanggung jawab untuk menampilkan antarmuka pengguna, mengelola interaksi pengguna, dan berkomunikasi dengan backend melalui API.
